## Report a Router

Keenetic, Netcraze, Teltonika and TR-064 are written from the vendors' documentation and have never met a real device; OPNsense, pfSense and VyOS were checked in virtual machines only. If you run one of them, an issue with the model, the firmware version and what worked or did not helps more than anything else. Please leave addresses, passwords and keys out of it.

## If the App Does Not Start

A desktop start that fails writes its cause to `NetworkHelm-startup-error.log` in the temporary folder: `%TEMP%` on Windows (paste it into the Explorer address bar), `/tmp` on Linux. A window that stops on an error writes it to `NetworkHelm-error.log` in the same folder and gives the full path in its message before it closes. Attach the file to an issue together with the system version and whether it runs in a virtual machine. If the installer or the portable EXE says the program does not support this version of Windows, you have Windows 7, 8 or 8.1, and the standard files need 64-bit Windows 10 or newer. The files marked `legacy` in the release are built for 64-bit Windows 7 SP1 and 8; I have not been able to run them there yet, so a report from such a machine is welcome.
